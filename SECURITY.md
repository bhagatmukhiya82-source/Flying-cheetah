## 🛡️ Reporting a Vulnerability

Flying Cheetah Labs takes security seriously. If you discover a security vulnerability in our codebase or cloud deployments, please report it privately:

- **Security Team Email**: `flyingcheetah.agency@gmail.com`
- **Subject Line**: `[SECURITY VULNERABILITY] <Brief Description>`
- **Direct Urgent Support**: `+91 99203 86421`

### Please include:
1. Detailed description of the vulnerability.
2. Steps to reproduce or proof-of-concept exploit.
3. Impact assessment and suggested mitigations.

We will acknowledge receipt within **24 hours** and work collaboratively on a fix prior to public disclosure.
